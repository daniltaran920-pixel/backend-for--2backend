# Move Backend API

Бэкенд-приложение на Node.js и Express для управления ролями пользователей, использующее Knex.js для работы с базой данных PostgreSQL.

## 🚀 Стек технологий

* **Node.js** (v24+)
* **Express** — веб-фреймворк
* **Knex.js** — SQL query builder
* **PostgreSQL** — база данных
* **dotenv** — управление переменными окружения

## 🛠️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd backend-for--2backend
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл **`.env`** в корневой папке проекта на основе примера `.envExample` и заполните данные для подключения к вашей PostgreSQL:

```env
DB_HOST=localhost
DB_PORT=5432
DB_USER=ваш_пользователь
DB_PASSWORD=ваш_пароль
DB_NAME=имя_вашей_базы_данных
PORT=3120
```

### 4. Запуск приложения
При первом запуске сервер автоматически проверит базу данных и создаст необходимые таблицы (`items` и `users`), если они отсутствуют.

```bash
node server.js
```
Сервер начнет прослушивание на порту `3120` (или указанном в `.env`).

## 📡 API Эндпоинты

### Пользователи (Users)

#### Изменение роли пользователя
Позволяет повысить роль пользователя по цепочке: `user` ➡️ `admin` ➡️ `superadmin`.

* **URL:** `/getRole`
* **Метод:** `POST`
* **Заголовки:** `Content-Type: application/json`
* **Тело запроса (JSON):**
  ```json
  {
    "id": 1
  }
  ```

* **Успешный ответ (200 OK):**
  ```json
  {
    "mes": "Роль успешно изменена на admin"
  }
  ```

* **Примеры ошибок:**
  * `401 Unauthorized / Bad Request` — если не передан ID (`{"mess": "Введите ID"}`).
  * `404 Not Found` — если пользователя нет в базе (`{"mes": "Пользователь не найден"}`).
